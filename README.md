# NAMAA · نماء

Smart agrivoltaics platform demo — static frontend for managing desert-land dual-use PV + agriculture (Vision 2030).

Prepared by **Fatma Ben Feguir**.

## Local

```bash
npm install
npm run dev
```

## Modules

- Main dashboard (solar, water, LER, microclimate)
- IoT & AI (sensor map, irrigation / shading recommendations)
- Precision drip irrigation
- Vertical farming / CEA
- Agrivoltaics energy routing
- CapEx / OpEx
- Sustainability reports (CSV / text export)
- Land allocation GIS
- Benchmarks & strategic goals
